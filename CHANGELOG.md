# Changelog

## 1.5.0

- New light novel section for `.epub` files, with its own reader, themes, fonts, table of contents and resume
  position, plus AniList matching.
- The top navigation fits on phones without sideways scrolling.
- The update server address is now empty by default. Add one in Settings, Updates if you host releases.
- `NOVEL_DIR` environment variable for Docker.
- Documentation rewritten and moved to `docs/`.
- Released under GPL-3.0-or-later.

## 1.4.x

- Anime section: HLS playback through ffmpeg, subtitle styling with JASSUB, season handling from AniList,
  show landing pages, filters and genre or tag browsing.
- Social page with AniList friend activity.
- Context menus, Show in folder and Properties.
- Auto scan, restart button, per-folder scans.

## 1.3.0 and earlier

Manga reader, doujin section with nhentai metadata, OCR chapter detection, AniList tracking, in-app updates and
Docker support.
